  FUNCIONALIDAD PRINCIPAL
================================================================================

✅ IMPORTACIÓN DE ARCHIVOS ZIP
   • Busca archivos ZIP en carpeta automáticamente
   • Valida formato de nombre: CUIL_PERIODO_presentacion_NRO.xml.zip
   • Descomprime y extrae XML
   • Crea registro en Tab60026 (auditoría)

✅ PROCESAMIENTO DE DATOS
   • Parsea XML SIRADIG v1.24+
   • Extrae deducciones y cargas de familia
   • Valida que empleado existe (por CUIL)
   • Actualiza Tab60022 (deducciones por empleado)
   • Crea/actualiza Employee Relative (cargas de familia)

✅ AUDITORÍA Y TRACKING
   • Registra todas las importaciones
   • Guarda: CUIL, período, fecha, usuario, estado
   • Captura errores y mensajes
   • Permite rollback manual si es necesario

✅ TRES FORMAS DE USAR
   1. Desde interfaz (Pag50161): "Importar Archivos SIRADIG"
   2. Desde código: Orquestador.ImportarYProcesarCarpeta()
   3. Automático: Job Queue + ProcesarImportacionesPendientes()

  INICIO RÁPIDO
================================================================================

1. COMPILAR
   └─ Compilar todos los archivos .al nuevos sin errores

2. CONFIGURACIÓN INICIAL
   └─ Verificar que Employee."Social Security No." tiene CUIL (11 dígitos)
   └─ Crear carpeta: C:\SIRADIG\2024\
   └─ Copiar archivos ZIP con patrón correcto

3. IMPORTAR
   └─ Buscar: "Importaciones SIRADIG"
   └─ Acción: "Importar Archivos SIRADIG"
   └─ Ingresar ruta: C:\SIRADIG\2024\
   └─ Responder: ¿Procesar automáticamente? Sí/No

4. VALIDAR
   └─ Revisar Tab60026 (auditoría)
   └─ Revisar Tab60022 (deducciones actualizadas)
   └─ Revisar Employee Relative (cargas familiares)

  REQUERIMIENTOS PREVIOS
================================================================================

✓ CUIL en Employee
  └─ Campo: Employee."Social Security No."
  └─ Formato: 11 dígitos sin guiones (ej: 20666666667)

  └─ Formato: CUIL_PERIODO_presentacion_NRO.xml.zip
  └─ Ejemplo: 20666666667_2024_presentacion_001.xml.zip

✓ Permisos de usuario
  └─ Lectura: carpeta con archivos ZIP
